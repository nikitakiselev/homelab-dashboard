# Установка и обновление

## Системные требования

Автоматическая установка: Debian 12+ или Ubuntu 22.04+, Python 3.10+ и работающий systemd. Для сборки центрального интерфейса поддерживаются x86_64 и ARM64. Нужен исходящий HTTPS-доступ к GitHub и системным репозиториям; центральному сервису при сборке также нужны nodejs.org и npm.

Установщик не меняет GPU-драйверы и правила firewall.

## Центральный сервис

```sh
curl -fsSL https://raw.githubusercontent.com/nikitakiselev/homelab-dashboard/main/install.sh | sudo sh
```

Скрипт устанавливает Python и зависимости сборки интерфейса; аппаратные утилиты и агент вместе с дашбордом не устанавливаются. При необходимости скачивает официальный Node.js 22, проверяет SHA-256 и использует его только для сборки. `npm ci` и сборка выполняются отдельным непривилегированным пользователем. Работающему центральному сервису Node.js не нужен.

Создаются пользователь `homelab`, служба `homelab-dashboard` и отдельный токен доступа. Дашборд работает от `homelab`, не собирает оборудование и не запускает агент. Для мониторинга этой же Linux-машины отдельно установите `homelab-agent` и добавьте в UI адрес `127.0.0.1`, порт 9108 и токен агента. Для локального подключения можно настроить агент на `server.bind: 127.0.0.1`. Базы истории обеих служб размещайте на SSD, чтобы их записи не мешали сну HDD.

После запуска установщик проверяет авторизованный `/api/hosts` и выводит адреса сервиса и токен входа. Не публикуйте токен в Issues или логах.

## Агент каждого наблюдаемого Linux-хоста

```sh
curl -fsSL https://raw.githubusercontent.com/nikitakiselev/homelab-dashboard/main/install.sh | sudo sh -s -- --agent
```

В этом режиме скачивается готовый Go-бинарник из GitHub Releases и проверяется SHA-256. Python, Go-компилятор и Node.js на хосте не нужны. Устанавливаются smartmontools/util-linux и, при обнаружении Intel GPU, intel-gpu-tools. Агент работает от root для чтения оборудования.

После запуска проверяется `/v1/metrics`; выводятся порт, токен и расположение YAML. Добавьте IP и токен в UI. Разрешите TCP 9108 только от центрального сервиса в уже используемом firewall.

Агент из скачанного через UI архива также устанавливается одной командой из распакованного каталога:

```sh
sudo sh deploy/install_agent.sh
```

## Обновление и откат

Для агента: `sudo homelab-agent upgrade`; доступна конкретная версия через `--version agent-v0.3.0`. Команда показывает текущую и доступную версии; при совпадении сообщает `Already up to date` без скачивания бинарника и перезапуска службы. При изменении версии показывает переход `старая -> новая`, проверяет API и откатывает бинарник и unit при ошибке.

Для центрального сервиса повторите ту же команду установки. Существующие токены, YAML и базы SQLite сохраняются. Для центрального сервиса новая версия сначала собирается в отдельном каталоге; установленные версии находятся в `/opt/homelab-dashboard/releases/`, активная — по ссылке `current`. При неуспешной проверке API восстанавливаются предыдущая ссылка и systemd-unit; ранее работавшая служба запускается заново. Откат кода не выполняет обратную миграцию SQLite.

Для установки конкретной ветки, тега или коммита передайте `--ref`:

```sh
curl -fsSL https://raw.githubusercontent.com/nikitakiselev/homelab-dashboard/main/install.sh | sudo sh -s -- --ref main
```

## Файлы и диагностика

| Назначение | Центральный сервис | Отдельный агент |
|---|---|---|
| Токен | `/etc/homelab/dashboard.env` | `/etc/homelab/agent.env` |
| Настройки | env и параметры CLI (`--retention-days`, `--bind`, `--port`, `--data`) | `/etc/homelab/agent.yaml` |
| SQLite | `/var/lib/homelab/dashboard.sqlite` | `/var/lib/homelab-agent/agent.sqlite` |
| Служба | `homelab-dashboard` | `homelab-agent` |

```sh
systemctl status homelab-dashboard
journalctl -u homelab-dashboard -n 50 --no-pager
# Для агента замените имя службы на homelab-agent.
```

Резервируйте SQLite при остановленной соответствующей службе. Удаление хоста из UI удаляет центральную копию истории; исходная база агента остаётся. Если машина по тому же IP заменена другой, удалите старую запись и добавьте новую.

Для чтения installer перед выполнением сохраните `install.sh` и запустите его после просмотра. Транспорт метрик пока HTTP: используйте доверенную LAN/VPN или собственную TLS-терминацию. Не открывайте порты в интернет.

## Удаление

[Удаление агента и центрального сервиса](uninstall.md): остановка и удаление программ с сохранением данных либо полная очистка настроек и истории.

При переходе со встроенного сборщика старый `collector.yaml` и история `local` сохраняются, но встроенный сбор не запускается. Подробнее: [переход со встроенного сборщика](architecture.md#переход-со-встроенного-сборщика).
