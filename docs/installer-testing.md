# Проверка установщика

Модульные тесты Go проверяют YAML, авторизацию API и совместимость SQLite. Python-тесты проверяют центральный сервис и его откат. Shell-скрипты проверяются `sh -n`.

Для интеграционной проверки используется изолированный Debian-контейнер с checkout, смонтированным read-only в `/repo`:

```sh
cd agent
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o ../releases/homelab-agent_linux_amd64 ./cmd/homelab-agent
cd ..
docker run --rm --mount type=bind,src="$PWD",dst=/repo,readonly debian:12-slim sh /repo/tests/installer_smoke.sh
```

Тест действительно устанавливает пакеты, собирает React-интерфейс, запускает Python-сервис и Go-агент от указанных в unit-файлах пользователей и проверяет авторизацию HTTP API. Затем повторяет установку, проверяет сохранение YAML/токена/истории и устанавливает отдельного агента.

В контейнере systemd не является PID 1: команды управления службами заменены тестовым shim, запускающим настоящую команду из unit-файла. Синтаксис unit-файлов отдельно проверяет `systemd-analyze verify`. Этот тест не доказывает поведение sandbox-настроек systemd и автозапуск после перезагрузки; их нужно проверять в полноценной VM/LXC. Shim блокирует запуск вне маркированного тестового контейнера и в установочный архив не входит.

Для проверки обновления Go-агента и отката при заведомо неисправном бинарнике:

```sh
docker run --rm --mount type=bind,src="$PWD",dst=/repo,readonly debian:12-slim sh /repo/tests/agent_install_smoke.sh
```

Тест использует порт 19108 из YAML, повторно устанавливает бинарник, затем пытается поставить неисправную версию. Проверяются возврат к предыдущей версии, доступность API, сохранение YAML, токена и накопленной истории.
