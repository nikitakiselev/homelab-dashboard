# Правила общения

В Issues, pull requests и обсуждениях проекта:

- Обсуждайте техническую проблему и аргументы; не переходите на личности.
- Не допускаются травля, угрозы, дискриминация и публикация чужих личных данных.
- Уважайте время участников: приводите воспроизведение, контекст и проверяемые факты.
- Не публикуйте секреты и сведения чужой инфраструктуры.

Maintainer может удалить нарушающий правила материал, закрыть обсуждение или ограничить участие. Сообщение о нарушении можно направить maintainer после согласования закрытого канала; не воспроизводите чужие личные данные в публичном Issue.

Правила применяются к площадкам этого репозитория.
