# Linux agent

Требования: Linux с systemd, Python 3.10+. Для SMART нужны smartmontools, util-linux и права root. Ubuntu, Debian и Proxmox используют один агент. Устанавливайте на физический хост, если нужны данные физического оборудования.

После публикации репозитория агент устанавливается одной командой:

```sh
curl -fsSL https://raw.githubusercontent.com/nikitakiselev/homelab-dashboard/main/install.sh | sudo sh -s -- --agent
```

Пока репозиторий приватный, скрипт нужно получить авторизованным Git-клиентом. Архив из UI уже содержит установщик и не требует скачивания приватного репозитория.

Для установки из архива распакуйте его и запустите:

```sh
tar -xzf homelab-agent.tar.gz
cd homelab-agent
sudo python3 deploy/install_agent.py
```

На Debian/Ubuntu установщик при необходимости ставит smartmontools и util-linux через apt-get. Для остальных дистрибутивов установите эти пакеты своим менеджером. Чтобы запретить установку пакетов, передайте `--skip-packages`. Проверка без изменений: `python3 deploy/install_agent.py --check`.

Для другого порта или выбора сетевых интерфейсов:

```sh
sudo python3 deploy/install_agent.py --port 9108 --interfaces enp3s0
```

Установка создаёт службу homelab-agent и уникальный токен в `/etc/homelab/agent.env`. Повторная установка сохраняет токен, историю и выбор интерфейсов. Данные: `/var/lib/homelab-agent/agent.sqlite`. Пакет не содержит данных хостов, токенов или frontend.

Посмотрите токен локально командой `sudo cat /etc/homelab/agent.env`. В дашборде нажмите «Добавить сервер», укажите частный IP этого сервера, порт и значение HOMELAB_AGENT_TOKEN. Firewall должен разрешать порт только от IP центрального сервиса. Установщик правила firewall не меняет.

По умолчанию служба снимает CPU/память/сеть раз в 5 секунд, SMART — раз в минуту. Эти интервалы, включение GPU/SMART, интерфейсы и срок хранения настраиваются в `/etc/homelab/agent.yaml`; обновление сохраняет файл. Токен хранится отдельно в `agent.env`. После правки YAML перезапустите службу. SMART и GPU опрашиваются отдельно, медленные диски не задерживают остальные метрики. По умолчанию история хранится на агенте 90 дней и догружается центральным сервисом при подключении. Во время остановки агента данные не собираются.

NVIDIA GPU: требуется уже установленный драйвер с nvidia-smi. AMD: доступны счётчики sysfs, если их предоставляет драйвер. Установщик не устанавливает GPU-драйверы. Intel i915: установите пакет intel-gpu-tools для счётчиков загрузки. Используется максимальная занятость движков; отдельная VRAM на встроенной Intel не показывается.

Диагностика:

```sh
systemctl status homelab-agent
journalctl -u homelab-agent -n 50 --no-pager
```

Транспорт HTTP рассчитан на доверенную LAN/VPN. Не открывайте агент в интернет. Удаление службы не удаляет историю: `sudo systemctl disable --now homelab-agent` останавливает сбор.
