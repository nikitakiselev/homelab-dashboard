# Безопасность

Проект находится в ранней разработке. Исправления готовятся для актуальной ветки `main`; отдельные гарантии поддержки старых версий и сроки ответа пока не установлены.

По умолчанию агент слушает только `127.0.0.1:9108`; доступ через LAN/VPN требует явного `server.bind`. Обновление сохраняет YAML, поэтому старые установки с `bind: 0.0.0.0` требуют ручного изменения.

Метрики передаются по HTTP с Bearer-токенами, без встроенного TLS. Разворачивайте сервисы в доверенной LAN/VPN; ограничивайте порт агента IP-адресом центрального сервиса. Отдельный Linux-агент читает оборудование от root. Токены, базы и сетевые сведения не должны попадать в публичные отчёты.

## Сообщить об уязвимости

Отдельный закрытый канал проекта пока не настроен. Создайте Issue только с просьбой согласовать приватный способ связи с [maintainer](https://github.com/nikitakiselev), без описания эксплуатации, токенов и данных инфраструктуры. После согласования передайте подробности закрытым способом.

Не публикуйте рабочий эксплоит или секреты в обычном Issue/PR. В сообщении maintainer нужны версия/коммит, затронутый компонент, последствия и минимальное воспроизведение на синтетических данных.
